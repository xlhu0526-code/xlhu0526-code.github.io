1. var，let和const的区别

   var：函数作用域，变量提升，全局对象（window.访问）
   let：块级作用域，暂时性死区（声明前无法访问）
   const：不能重新赋值，变量引用的不变性
   最佳实践：优先使用const，告别var

2. 数据类型和typeof

   原始数据类型：string,number,boolean,symbol,bigint,undefined，null
   对象数据类型：Array，Object，Function，Date等
   陷阱：typeof null 返回 "object"（历史遗留 bug：早期实现用低位类型标签，null 是空指针全 0，标签位与 object 相同；因向后兼容无法修改）
   判断null：使用val===null
   判断数组：Array.isArray(arr),
   判断对象类型：Object.prototype.toString.call([]);//"[object Array]"

3. structuredClone 深拷贝

   内置全局函数（Node 17+ / 现代浏览器原生支持），比 JSON.parse(JSON.stringify()) 更强
   支持：循环引用、Date/RegExp/Map/Set/ArrayBuffer/TypedArray 等复杂类型
   无法拷贝：函数、DOM 节点（抛 DataCloneError）
   可以拷贝：Error 对象（Error/TypeError/RangeError 等）——常见误区，其实可以
   注意：不保留原型链（结果退化为普通 Object），getter 会被求值成普通值属性，Symbol 键丢失
   转移（transfer）：structuredClone(obj, { transfer: [arrayBuffer] })，转移后原对象不可再用

   手写深拷贝函数

   ```
   function deepClone(obj, hash = new WeakMap()) {
      if (obj === null || typeof obj !== 'object') {
         return obj;
      }
      if(hash.has(obj)) {
         return hash.get(obj);
      }
      let clone = Array.isArray(obj) ? [] : {};
      hash.set(obj, clone);
      for (let key in obj) {
         if (Object.hasOwn(obj, key)) {
               clone[key] = deepClone(obj[key], hash);
         }
      }
      return clone;
   }
   ```

5. for in和Object.keys()有何不同？

   for in会遍历自身和原型链上的可枚举属性。

   Object.keys(obj)只返回对象自身的可枚举属性。

   Object.getOwnPropertyNames 返回自身字符串键的全部属性（含不可枚举，但不含 Symbol）

   对象自身「全部键」的几种取法对比：

   | 方法                           | 范围                                            |
   | ------------------------------ | ----------------------------------------------- |
   | `for in`                       | 自身+原型链+可枚举+字符串键                     |
   | `Object.keys`                  | 自身 + **可枚举** + 字符串键                    |
   | `Object.getOwnPropertyNames`   | 自身 + **含不可枚举** + 字符串键（不含 Symbol） |
   | `Object.getOwnPropertySymbols` | 自身 + Symbol 键                                |
   | `Reflect.ownKeys`              | 自身 + 全部键（字符串 + Symbol，含不可枚举）    |

   要点：`Object.getOwnPropertyNames` **拿不到 Symbol 键**，要 Symbol 用 `Object.getOwnPropertySymbols`，要字符串+Symbol 全拿用 `Reflect.ownKeys`；`for...in` 会带上原型链继承来的可枚举属性，故与 `Object.keys` 结果可能不同。
