亮点
  • 分布式任务调度框架：基于 Redis 分布式锁 + 定时轮询，保证任务在队列中的有序调度；基于注解的事件驱动通信层（注解扫描 + 反射 + Handler 注册），解耦 Launch / Terminate / Release 等多种任务生命周期事件；使用 BRPC 发送事件，通过 Protobuf → JSON → 领域对象的反序列化链路，实现 gRPC 消息到业务处理方法的自动路由；
  • 异步任务完成检测：针对长时仿真任务，采用进度线程 + 数据库轮询，结合数据库状态机（init / launch / inprogress / success / failed / stopped）跟踪任务状态；
  • 自适应资源分配：依据网元数量分档设置内存、CPU 等资源，随任务生命周期完成资源的分配与释放；利用 Redis 锁与资源分配表解决多任务并发执行的资源竞争问题。
成果
  • 平台支撑 500+ 网元规模仿真，稳定运行超两年；
  • 性能优化后 OOM 问题消除，大规模仿真内存峰值显著降低；
  • 自适应资源分配方案使多任务并发资源冲突降为 0；
